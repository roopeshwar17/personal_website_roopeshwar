# Roopeshwar Jonnakuti — Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Deploy

Push this repository to GitHub and import it into Vercel, or deploy the `dist` folder to any static host.

## Customize

Main portfolio content is in `src/main.jsx`.
Styling is in `src/styles.css`.
